# AppleScript — App Remote Control Reference

> **Doctrine:** AppleScript is for **app lifecycle and navigation only**. It is NOT your editing engine.
>
> **python-pptx + lxml = the editor.** All content and design changes — text, fonts, colors, positions, fills, sizes, shadows, letter-spacing, gradients, corner radius, transparency, shape creation — go through python-pptx. No exceptions.
>
> **AppleScript = the hands around the editor.** Open files. Close files. Quit the app. Navigate slides. Start a slideshow. Take a screenshot of the current window. Read shape inventory when you need a quick look.
>
> This is the lesson from every failed "quick live tweak" attempt: half the time the property you need (letter-spacing, gradient, alpha, radius) isn't exposed to AppleScript anyway, and the other half the API is unreliable (font color, `top of shape`). Skip the detour — rebuild with python-pptx, reload.

## PowerPoint Presence Check

**Check before any AppleScript command.** Microsoft PowerPoint.app is NOT guaranteed to be installed — many macOS users only have Keynote, or no presentation app at all. The .pptx file is generated by python-pptx regardless; only the open/quit/navigate steps need PowerPoint.

### Detect PowerPoint

```bash
# Returns the app bundle ID if installed, exits non-zero if not.
osascript -e 'id of app "Microsoft PowerPoint"' 2>/dev/null
```

### Python wrapper

```python
import subprocess

def powerpoint_installed():
    """Return True if Microsoft PowerPoint.app is installed on this Mac."""
    result = subprocess.run(
        ['osascript', '-e', 'id of app "Microsoft PowerPoint"'],
        capture_output=True, text=True
    )
    return result.returncode == 0 and result.stdout.strip().startswith('com.microsoft')
```

### Graceful fallback pattern

```python
if powerpoint_installed():
    subprocess.run(['osascript', '-e',
                    'tell application "Microsoft PowerPoint" to quit saving no'])
    # ... wait for process exit, rebuild, reopen ...
    subprocess.run(['open', '-a', 'Microsoft PowerPoint', pptx_path])
    print(f"✅ Opened {pptx_path} in PowerPoint.")
else:
    # PowerPoint not installed — skip all AppleScript steps.
    print(f"ℹ️ Microsoft PowerPoint is not installed.")
    print(f"📄 File saved at: {pptx_path}")
    print(f"   Open it in Keynote, LibreOffice, or your preferred .pptx viewer.")
```

**Never fail the build because PowerPoint is missing.** The .pptx file is the real deliverable — opening it is a convenience.

## Doctrine & Decision Rules

| Task | Engine | Why |
|---|---|---|
| Build / rebuild a deck | **python-pptx** | The editor |
| Change any text content | **python-pptx** | The editor |
| Change any font property (size, name, bold, color, spacing) | **python-pptx** | AppleScript color + spacing are unreliable or missing |
| Change any shape property (position, size, fill, line, shadow, radius, alpha, rotation, z-order) | **python-pptx** | Full control, predictable output |
| Add/remove shapes, text boxes, images, charts, tables | **python-pptx** | The editor |
| Change slide background | **python-pptx** | Gradient support via lxml |
| Speaker notes | **python-pptx** | Consistent with rest of edit flow |
| Open a `.pptx` file | **AppleScript** | App lifecycle |
| Close / save / quit PowerPoint | **AppleScript** | App lifecycle |
| Reload after python-pptx rebuild | **AppleScript** | App lifecycle — see [The Reload Pattern](#the-reload-pattern-critical) |
| Navigate to slide N | **AppleScript** | UI navigation |
| Start / stop slideshow | **AppleScript** | UI control |
| Take a screenshot of the open window | **AppleScript + screencapture** | Verification only |
| Read shape inventory for a quick look | **AppleScript** OR python-pptx | Either works; python-pptx is more reliable |

**The rule that eliminates 90% of bugs:** If you find yourself about to write an AppleScript that sets ANY property — stop. Go rebuild with python-pptx instead. The round-trip (quit → rebuild → reopen) is faster and more reliable than fighting AppleScript's missing properties.

## The Reload Pattern (CRITICAL)

**This is the #1 source of "my changes didn't appear" bugs.**

When python-pptx rewrites a `.pptx` file that PowerPoint currently has open, PowerPoint does NOT automatically re-read from disk. Worse: `open -a "Microsoft PowerPoint" file.pptx` will see the app is already running with that file open and just bring the existing (stale) window to the front — it does NOT re-read from disk.

The ONLY reliable reload pattern:

```bash
# 1. QUIT the entire app (not just close the document)
osascript -e 'tell application "Microsoft PowerPoint" to quit saving no'

# 2. WAIT for the process to actually exit
while pgrep -x "Microsoft PowerPoint" > /dev/null; do sleep 0.2; done

# 3. NOW run the python rebuild
python3 build_deck.py

# 4. Reopen
open -a "Microsoft PowerPoint" "/absolute/path/to/file.pptx"
```

**Why each step matters:**
- `quit saving no` — kills the entire app process and releases all file handles. `close active presentation` is unreliable (may silently fail, may trigger save prompts, may leave app holding the file).
- `while pgrep` — `quit` is async. If you start the rebuild before the process is gone, you may write to a file the app is still finalizing, or hit file-lock errors.
- Don't use `2>/dev/null` on the `osascript` call during debugging — if `quit` fails (modal dialog, permission issue) you need to see the error.

**If PowerPoint isn't running in the first place:** Skip steps 1–2. Just rebuild and `open`.

## Presentation Lifecycle

```applescript
-- Open a file
tell application "Microsoft PowerPoint"
    activate
    open POSIX file "/absolute/path/to/file.pptx"
end tell

-- Save the active presentation
tell application "Microsoft PowerPoint"
    save active presentation
end tell

-- Export as PDF
tell application "Microsoft PowerPoint"
    save active presentation in ¬
        ((path to downloads folder as text) & "output.pdf") ¬
        as save as PDF
end tell

-- Quit the app entirely (preferred for reload pattern)
tell application "Microsoft PowerPoint" to quit saving no

-- Get presentation metadata
tell application "Microsoft PowerPoint"
    set pName to name of active presentation
    set sCount to count of slides of active presentation
end tell
```

**Shell one-liners (preferred for build scripts):**
```bash
# Open
open -a "Microsoft PowerPoint" "/abs/path/file.pptx"

# Quit
osascript -e 'tell application "Microsoft PowerPoint" to quit saving no'

# Wait for exit
while pgrep -x "Microsoft PowerPoint" > /dev/null; do sleep 0.2; done
```

## Slideshow Control

```applescript
-- Start slideshow
tell application "Microsoft PowerPoint"
    activate
    try
        run slide show slide show settings of active presentation
    end try
end tell

-- Fallback via System Events (more reliable)
tell application "Microsoft PowerPoint"
    activate
    delay 0.3
end tell
tell application "System Events"
    tell process "Microsoft PowerPoint"
        click menu item "Play from Start" of menu "Slide Show" of menu bar 1
    end tell
end tell

-- Exit slideshow
tell application "Microsoft PowerPoint"
    try
        set theShow to slide show window 1
        tell theShow to exit slide show
    end try
end tell
```

> **Known issue:** `run slide show` occasionally fails with `Parameter error (-50)`. Always wrap in `try` and fall back to System Events menu clicks.

## Read-Only Inspection

Fine for quick "what's on this slide?" reads. For anything you'll act on, prefer python-pptx — it gives you EMUs, font color RGB, and structured data rather than AppleScript's stringified output.

```applescript
-- List shapes on active slide
tell application "Microsoft PowerPoint"
    tell slide 2 of active presentation
        set output to ""
        repeat with i from 1 to (count of shapes)
            set s to shape i
            set output to output & i & ": " & (name of s) & ¬
                " @ (" & (left position of s) & "," & ¬
                (width of s) & "x" & (height of s) & ")"
            try
                if has text frame of s then
                    set t to content of text range of text frame of s
                    if length of t > 0 then
                        if length of t > 60 then set t to text 1 thru 60 of t
                        set output to output & " → " & t
                    end if
                end if
            end try
            set output to output & return
        end repeat
        return output
    end tell
end tell
```

**Python-pptx equivalent (preferred):**
```python
from pptx import Presentation
prs = Presentation('/path/to/file.pptx')
for i, slide in enumerate(prs.slides):
    print(f"--- Slide {i+1} ---")
    for shape in slide.shapes:
        print(f"  [{shape.name}] L={shape.left} T={shape.top} "
              f"W={shape.width} H={shape.height}")
        if shape.has_text_frame:
            print(f"    → {shape.text_frame.text[:60]!r}")
```

## Screenshot / Screen Capture Trigger

For verifying a slide visually (e.g., after rebuild, before declaring done):

```bash
# Bring PowerPoint to front, navigate to slide N, then screenshot
osascript <<'EOF'
tell application "Microsoft PowerPoint"
    activate
    set theView to view of active window
    go to slide theView number 2
end tell
EOF
sleep 0.8
# Capture the active window (user can interactively click the target)
screencapture -iW /tmp/slide2.png
```

`screencapture -iW` prompts for window click and captures just that window. Pair with `macos-utilities` skill for a non-interactive version.

## Unit System

AppleScript uses **points** (1 inch = 72 points).
python-pptx uses **EMUs** (1 inch = 914400 EMUs).

```
EMU = points × 12700
points = EMU ÷ 12700

Widescreen slide:
  Points: 960 × 540
  EMUs:   12192000 × 6858000
```

You'll rarely need this now that AppleScript isn't writing positions. Kept for read-only inspection math.

## ⚠ Legacy: Live Edit Patterns (Do Not Use)

> **Everything below this line is DEPRECATED** for this skill's workflow. These patterns are preserved for reference only — in case you're debugging someone else's AppleScript, or the python-pptx path is genuinely unavailable (e.g., file is locked open with unsaved edits the user wants to preserve).
>
> **For the skill's standard workflow: use python-pptx.** If you catch yourself reaching for any of the code below, stop and ask yourself: "Could I just rebuild the file and reload?" The answer is almost always yes.

### Why these were demoted

| Property / Operation | Problem with AppleScript |
|---|---|
| Font color | Unreliable; `fore color of font color` has inconsistent behavior across versions |
| Letter spacing (tracking) | Not exposed in the dictionary at all — requires `rPr spc` via lxml |
| Gradient fills (shape or background) | Not exposed — requires `<a:gradFill>` via lxml |
| Corner radius on rounded rects | Not exposed — requires `a:avLst` via lxml |
| Transparency / alpha on text | Not exposed — requires `a:alpha` via lxml |
| Paragraph space-before / space-after | Spotty support |
| Line spacing | Spotty support |
| Mixed runs in one paragraph (bold + normal) | Hit-or-miss |
| `top of shape` read | Throws `-10003` on some versions |
| `make new picture` | Fails — cannot insert images |
| Copy shape across slides | `copy` not understood |
| Tables, charts, slide transitions | Not exposed |

In practice: the moment your "small tweak" touches color, spacing, radius, or gradient, AppleScript can't help you. So the skill's policy is to never start down this path.

### The old patterns (kept for archaeological reference)

**Text replacement:**
```applescript
tell application "Microsoft PowerPoint"
    tell slide 2 of active presentation
        set content of text range of text frame of shape "TextBox 6" to "New text"
    end tell
end tell
```

**Font size / bold / italic / name:**
```applescript
tell application "Microsoft PowerPoint"
    tell slide 2 of active presentation
        set f to font of text range of text frame of shape "TextBox 4"
        set font size of f to 24
        set bold of f to true
        set italic of f to false
        set font name of f to "Georgia"
    end tell
end tell
```

**Position and size:**
```applescript
tell application "Microsoft PowerPoint"
    tell slide 2 of active presentation
        set s to shape "TextBox 6"
        set left position of s to 200
        set width of s to 500
        set height of s to 100
    end tell
end tell
```

**Shape fill (solid only, RGB packed as long int `R*65536 + G*256 + B`):**
```applescript
tell application "Microsoft PowerPoint"
    tell slide 2 of active presentation
        set sh to shape "Shape_1"
        set fore color of fill format of sh to 200 * 65536 + 16 * 256 + 46
        set transparency of fill format of sh to 0.2
    end tell
end tell
```

**Z-order / visibility / rotation:**
```applescript
set z order of s to bring to front    -- or: send to back, bring forward, send backward
set visible of s to false
set rotation of s to 15
```

**Speaker notes:**
```applescript
tell application "Microsoft PowerPoint"
    tell slide 1 of active presentation
        set np to notes page of it
        set content of text range of text frame of shape 2 of np to "Notes text"
    end tell
end tell
```
