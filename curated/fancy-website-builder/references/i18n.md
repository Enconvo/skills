# i18n — multi-language support

Every shell ships with a vanilla loader. No React-i18next, no framework. Adding a language = editing one JSON file.

## Data-attribute contract

Mark translatable nodes with `[data-i18n]`:

```html
<h1 data-i18n="hero.title">A marketing mind, after hours.</h1>
<p data-i18n="hero.subtitle">I think about brands the way a bartender thinks about a room.</p>
<button data-i18n="cta.brief">Send the napkin</button>
```

For attributes (alt, placeholder, aria-label), use `[data-i18n-attr]`:

```html
<input data-i18n-attr="placeholder" data-i18n-attr-placeholder="form.email_placeholder" />
<img alt="Hero" data-i18n-attr="alt" data-i18n-attr-alt="hero.image_alt" />
```

## i18n JSON format

`i18n/en.json`:
```json
{
  "hero.title": "A marketing mind, after hours.",
  "hero.subtitle": "I think about brands the way a bartender thinks about a room.",
  "cta.brief": "Send the napkin",
  "form.email_placeholder": "where to write back",
  "hero.image_alt": "Cleo on a Singapore rooftop"
}
```

`i18n/zh.json`:
```json
{
  "hero.title": "营销脑子，下班后。",
  "hero.subtitle": "我思考品牌的方式，像调酒师思考一桌客人。",
  "cta.brief": "递个餐巾纸",
  "form.email_placeholder": "回信地址",
  "hero.image_alt": "Cleo 在新加坡顶楼"
}
```

Keys MUST match across language files. Missing keys fall back to English.

## Loader (embedded in every shell)

```html
<script id="i18n-loader">
(function() {
  var URL_LANG = new URLSearchParams(location.search).get('lang');
  var NAV_LANG = (navigator.language || 'en').slice(0, 2);
  var SUPPORTED = window.__I18N_LANGS__ || ['en'];
  var lang = SUPPORTED.includes(URL_LANG) ? URL_LANG
           : SUPPORTED.includes(NAV_LANG) ? NAV_LANG
           : 'en';
  document.documentElement.setAttribute('lang', lang);

  fetch('i18n/' + lang + '.json').then(function(r) {
    if (!r.ok) throw new Error('lang not found');
    return r.json();
  }).then(function(dict) {
    document.querySelectorAll('[data-i18n]').forEach(function(el) {
      var key = el.getAttribute('data-i18n');
      if (dict[key]) el.textContent = dict[key];
    });
    document.querySelectorAll('[data-i18n-attr]').forEach(function(el) {
      el.getAttribute('data-i18n-attr').split(',').forEach(function(attr) {
        var key = el.getAttribute('data-i18n-attr-' + attr.trim());
        if (key && dict[key]) el.setAttribute(attr.trim(), dict[key]);
      });
    });
    document.documentElement.classList.add('i18n-ready');
  }).catch(function() {
    // English fallback already in DOM; just mark ready
    document.documentElement.classList.add('i18n-ready');
  });
})();
</script>
```

The shell sets `window.__I18N_LANGS__ = ['en','zh','ja']` (etc.) before this script runs, listing the languages this site actually has. The loader picks the right one from URL `?lang=` → browser locale → English fallback.

## CSS hooks

Hide content until i18n loads to prevent FOUC:
```css
html:not(.i18n-ready) [data-i18n] { visibility: hidden; }
```

Or for production sites where SEO matters, leave the English defaults visible (they're already the right content) and let the loader swap them in place — no FOUC, just a flash if a non-English locale is detected.

## Adding a new language

1. Copy `i18n/en.json` → `i18n/<new_lang>.json`.
2. Translate values (keep keys identical).
3. Edit the shell's `<head>` to add the language to `window.__I18N_LANGS__`.

Done. The loader picks it up automatically.

## Language codes

Use ISO 639-1 two-letter codes (always lowercase):

| Code | Language |
|---|---|
| `en` | English |
| `zh` | 中文 (simplified) |
| `ja` | 日本語 |
| `ko` | 한국어 |
| `es` | Español |
| `fr` | Français |
| `ru` | Русский |
| `de` | Deutsch |
| `pt` | Português |
| `it` | Italiano |
| `ar` | العربية (RTL — needs additional `dir="rtl"` toggling) |
| `he` | עברית (RTL) |

For `zh-Hant` / `pt-BR` / `en-GB` style regional variants, use the longer code as a key suffix and update the URL/`navigator.language` matching accordingly. Keep it simple for v0.1.

## Tone preservation in translation

When running `i18n_translate.py`, the prompt instructs the LLM to:

- Preserve **brand voice** (intimate, after-hours, editorial — not corporate)
- Keep **personal pronouns** consistent (I / my / 我 / 私 / etc. — not "we" if the original is first-person singular)
- Translate **idioms culturally**, not literally ("after hours" → 下班后 not 在小时之后)
- Keep **proper nouns** untranslated unless they have a canonical localised form
- Match **line break / punctuation rhythm** of the original where it carries weight

Review machine output for at least one language before shipping; LLM translations are good but not perfect, especially for poetic/editorial copy.
